# sneha-arts.github.io

This repository contains a small static website for Sneha — an acrylic landscape and portrait artist.

Pages included:
- `index.html` — Home and featured works
- `gallery.html` — Full gallery (images live in `assets/`)
- `about.html` — Artist bio
- `contact.html` — Contact form (mailto)

To publish as GitHub Pages for a user/organization site (sneha-arts.github.io):

1. Commit and push this repository to the `main` branch of the `sneha-arts.github.io` repository on GitHub.
2. GitHub will automatically publish the `main` branch for a repository named `sneha-arts.github.io`.
3. Visit https://sneha-arts.github.io after a minute or two.
